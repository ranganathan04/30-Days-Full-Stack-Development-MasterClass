
GIT : LOCAL COLLABORATION

WHAT IS GIT ?
    A VERSION CONROL SYSTEM TO TRACK CHANGES IN YOUR CODE.

WHY IS GIT ?
   MANAGE DIFFERENT VERSION OF PROJECT
   CODE BACKUP
   COLLABORATION
   KEEPING TRACK OF EVERY CHANGE MADE TO YOUR CODE
   SEEING WHO CHANGED THE PROJECT

STEPS :
    STORES YOUR PROJECT 
    COPY OF THE PROJECT 
    STAGES AND COMMIT CHANGES 
    BRANCHES
    MERGES 
    PULLS 
    PUSHES

EXAMPLE :

GENERAL FILE = CLIENT (REPOSITORY) - BACKUP

TWO DEVELOPERS

ONE FILE - TWO BRANCHES
